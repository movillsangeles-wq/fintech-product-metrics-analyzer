# B2B Fintech & Corporate Card Analytics Engine

A lightweight Python & SQL portfolio analytics tool designed for product managers and technical leads to evaluate B2B payment unit economics, card cohort activation, interchange margins, and default risk exposure.

## Key Modules
1. **Card Portfolio Unit Economics Simulator (`card_portfolio_analysis.py`):** Calculates gross interchange revenue, reward program liabilities (lounge/travel), operating expenses, and net contribution margins per active cardholder cohort.
2. **SQL Funnel & Activation Queries:** Pre-built analytical queries to track merchant/cardholder activation and transaction drop-off across cross-border and domestic rails.

## Tech Stack
- **Language:** Python 3.10+
- **Libraries:** Pandas, NumPy
- **Database / BI:** SQL (PostgreSQL / Metabase compatible)
